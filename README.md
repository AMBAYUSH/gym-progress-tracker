
# 💪 Gym Progress Tracker

A responsive fitness tracking web application built using HTML, CSS, and JavaScript.

🔗 **[Live Demo](https://ambayush.github.io/gym-progress-tracker/)**

## 🚀 Features

- Add, edit, and delete workouts
- Track sets, reps, and weight
- Interactive strength progress charts
- Estimated one-rep max (1RM) tracking
- Personal records for each exercise
- Workout search, filtering, and sorting
- Export workout history to CSV
- Automatic saving using localStorage
- Responsive dark-themed interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Git & GitHub
- GitHub Pages

## 📊 How It Works

1. Enter your exercise details.
2. Save your workout.
3. View your workout history.
4. Track your personal records.
5. Analyze strength progress through charts.

## 💻 Run Locally

1. Clone this repository.
2. Open the project in VS Code.
3. Open `index.html` using Live Server.
